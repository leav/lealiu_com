Beaver'n Beaver

Beaver 'n Beaver

Project Type: Digital Game

Date: 2015

Members: Lea Liu, Song Ye

My Role: Game Designer, Game Artist, Audio Designer

Beaver'n Beaver is a two-player button smashing game. Players control their own beaver to bite down the tree and push it towards the other side. There are three available actions: “bite” can bite down the tree to make it easier to push, “push” can push the tree towards the other side, and “attack” can interrupt opponent’s push. Since these actions work in a rock-paper-scissor way, players have to put in some strategy when they button smash.
