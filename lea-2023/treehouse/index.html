Treehouse Tribe

Treehouse Tribe is a Lego-Based board game featuring building system and resource management systems. The purpose of this game is to build a tree house with Lego bricks under a competitive environment. With worker placement phase and building phase, players are not only expected to fight against each other but also have to build a strong and fascinated tree house at same time.
