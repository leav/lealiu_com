Lea Liu's Secret-Color Chamber

The Lea Liu’s Secret Color Chamber is my portfolio website. Visitors can either browse the site using the navigation tabs, or flip through it like a book. Additionally, the avatar in the front page can help visitor especially HR to locate their most interested information.

To set the mood, the illustration on the front page showcases Lea’s work environment and her hobbies. There are also some easter eggs laying around for the more curious and visitors.

Project Type: Website

Date: 2014

Members: Lea Liu, Song Ye

My Role: Visual Designer,illustrator, UI/UX Designer
